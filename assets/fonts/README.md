# Instrument Sans

The Panorama interface uses Instrument Sans as the CSS family `BOOM Sans`.
Original BOOM logo artwork and Solari lettering remain separate.

Variable weights400–700, normal style, Latin and Latin extended WOFF2. Font files
are served from this repository; visitors do not contact a font provider.
`font-display: swap` preserves readable fallback text while loading.

- Source: https://github.com/google/fonts/tree/main/ofl/instrumentsans
- Web files: Google Fonts CSS API, Instrument Sans v4, retrieved2026-11-05.
