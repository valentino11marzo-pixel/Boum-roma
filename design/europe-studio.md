## First independent review

Claude returned a source-grounded critique in the linked session on11 November:
keep the bands still, reveal architectural masses rather than mainly fading
them, finish with the normalized gold strokes, and compare actual animated
frames with the canonical logo. It challenged tilted planes as a possible
cardboard effect, warned about opacity over overlapping geometry and about
external SVG readiness, and proposed faster repeat selections.

The integration uses that critique to test structural solidity, exact painted
handoff and loading/cancellation behavior. The new sprite gives individual
canonical paths IDs, so gold lines can be independently animated through uses;
the baseline reviewed by Claude did not yet contain those IDs. Geometry is not
copied into another authored source. The longer focal sequence is an explicit
change from the old420ms band effect; commercial actions never wait for it and
rapid retargeting settles immediately. These decisions need browser evidence,
not agreement between two models. Browser evidence led to one parsed canonical
asset with local definitions after external SVG instancing proved unreliable.
Shared drawing coordinates and explicit strokes corrected the measured dense
display mismatch. These are accepted implementation changes from the review.

## Each iteration

1. Name one customer problem and the specific surface; link the current source,
   Preview, accepted visual direction and any relevant reference.
2. Give the independent reviewer the same brief. Ask what should be rejected,
   not simply whether the proposal looks good.
3. Record the accepted change and the reason for declining alternatives. Assign
   exclusive file ownership before parallel implementation.
4. Review the real browser at native speed and selected frames, then exercise
   mobile, keyboard, reduced motion, cancellation and the actual service path.
5. Publish the tested branch Preview. Production remains the normal main-merge
   process. Update this brief only when the product direction changes.

## Acceptance evidence

The city, fee, conditions and next action update without waiting for decoration.
There is no control movement, scene resizing or shift into the Solari. The final
logo equals the original geometry; windows, arches and gold lines remain intact.
One finite construction has no idle work or queued replay. Quiet modes retain
the complete mark and immediate feedback. Actual rendered frames and interruption
tests matter more than a screenshot of the final poster.

Conversion remains a hypothesis to measure after a controlled launch: service
selection, valid continuation, completed enquiry and abandonment, interpreted
alongside performance and user feedback. Visual spectacle alone is not success.
